# 🌌 Interactive 3D Dreamscapes 

An immersive, dynamic 3D web experience built with **Three.js** and procedural generation. Explore vibrant, motion-driven visual worlds featuring custom wireframes, atmospheric sky-to-ground gradients, soaring bird vectors, soft cloud particle systems, and audio-reactive elements.


## 🛠️ Technical Stack

* **Core Engine:** [Three.js](https://threejs.org/) (WebGL Rendering Engine)
* **Graphics Techniques:**
  * Procedural Geometry & BufferAttribute array updates
  * Custom Canvas Textures & Radial Gradient Alpha Maps
  * Particle Systems (`THREE.Points` with `AdditiveBlending`)
  * Dynamic `Wireframe` and `LineSegments` geometry for low-poly aesthetics
* **Styling & Web UI:** HTML5, CSS Variables, Google Fonts (*Playfair Display*, *Plus Jakarta Sans*)
